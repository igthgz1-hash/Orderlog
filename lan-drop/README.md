# LAN Drop — ส่งไฟล์ระหว่างมือถือกับ PC ผ่านเว็บเบราว์เซอร์ (สองทาง)

ทางเลือกที่ **ทำงานได้แน่นอน** แทนการเลียนแบบโปรโตคอล AirDrop (ดู `../airdrop-tool/`
ซึ่งยังติดปัญหา BLE discovery ที่ Apple ไม่เปิดเผยสเปก) — วิธีนี้ใช้แค่ HTTP ธรรมดา
กับหน้าเว็บเดียว ใช้ได้กับมือถือทุกยี่ห้อ (iPhone, Samsung, Android อื่นๆ) โดยไม่ต้อง
ติดตั้งแอปเพิ่ม ส่งไฟล์ได้ทั้งสองทาง:

- **มือถือ → PC**: อัปโหลดผ่านฟอร์มบนหน้าเว็บ
- **PC → มือถือ**: เอาไฟล์ไปวางในโฟลเดอร์ที่กำหนด (`--send-dir`) แล้วมันจะขึ้นเป็น
  ลิงก์ดาวน์โหลดบนหน้าเว็บเดียวกันให้มือถือแตะโหลดได้เลย

## ติดตั้งแบบอัตโนมัติ (แนะนำ — ทำครั้งเดียวต่อเครื่อง)

**Windows:** เปิด PowerShell **แบบ Administrator** แล้วรัน (จำเป็นต้องเป็น Admin
เพื่อเปิดพอร์ตในไฟร์วอลล์ให้อัตโนมัติ):
```powershell
cd lan-drop
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
.\install.ps1
```
จะได้ shortcut ชื่อ "LAN Drop" บนหน้า Desktop ไว้ดับเบิลคลิกเปิดใช้งานได้เลยทุกครั้ง
โดยไม่ต้องเปิด PowerShell/พิมพ์คำสั่งอีก (ถอนการติดตั้งด้วย `.\uninstall.ps1`)

**macOS / Linux:**
```bash
cd lan-drop
./install.sh
```
จะได้คำสั่ง `lan-drop` ไว้เรียกใช้ได้จากเทอร์มินัล

## วิธีใช้แบบรันเอง (ไม่ผ่านตัวติดตั้ง)

```bash
cd lan-drop
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python3 server.py --name "PC ของฉัน" --out-dir ~/Downloads/LanDrop
```

จะเห็น QR code แสดงในเทอร์มินัลทันที:

### ส่งจากมือถือไป PC

1. เอามือถือ (ต้องต่อ **Wi-Fi วงเดียวกัน** กับ PC) สแกน QR code นั้น หรือพิมพ์ URL
   ที่แสดงไว้ (เช่น `http://192.168.1.74:8000/`) ในเบราว์เซอร์เอง
2. หน้าเว็บจะเปิดขึ้นมาพร้อมฟอร์มเลือกไฟล์ — เลือกรูป/ไฟล์ที่ต้องการส่ง (เลือกได้
   หลายไฟล์พร้อมกัน) แล้วกด "ส่งไฟล์"
3. ไฟล์จะถูกบันทึกลง `--out-dir` ที่ตั้งไว้ทันที (ค่าเริ่มต้น `~/LanDropReceived`) และ
   ขึ้นในรายการ "ไฟล์ที่ได้รับแล้ว" บนหน้าเว็บให้เห็นว่าส่งสำเร็จ

### ส่งจาก PC ไปมือถือ

1. เอาไฟล์ที่จะส่งไปวางไว้ในโฟลเดอร์ `--send-dir` (ค่าเริ่มต้น `~/LanDropToSend` —
   สร้างให้อัตโนมัติตอนเริ่มรัน)
2. ที่มือถือ เปิด URL เดิม (หน้าเดียวกับตอนส่งไฟล์เข้า) จะเห็นหัวข้อ "ไฟล์จาก PC
   (แตะเพื่อดาวน์โหลด)" พร้อมรายชื่อไฟล์ทั้งหมดในโฟลเดอร์นั้น
3. แตะชื่อไฟล์เพื่อดาวน์โหลด — รูปภาพจะเปิดในเบราว์เซอร์ให้กดค้าง (long-press) เพื่อ
   บันทึกลง Photos ได้เลย ส่วนไฟล์ประเภทอื่น (เอกสาร, zip ฯลฯ) จะดาวน์โหลดเข้า Files
   app โดยตรง

## ทำไมถึงมั่นใจว่าใช้ได้จริง

- ใช้ HTTP (ไม่ใช่ HTTPS) ธรรมดา ไม่มี certificate ให้เบราว์เซอร์เตือน
- ฟอร์มอัปโหลดไฟล์เป็นมาตรฐานเว็บพื้นฐาน (`multipart/form-data`) ที่เบราว์เซอร์ทุก
  ยี่ห้อรองรับมานานแล้ว ไม่ต้องอาศัยการเดาโปรโตคอลที่ Apple ไม่เปิดเผย
- ทดสอบแล้วในเครื่อง: อัปโหลดไฟล์ข้อความและไฟล์ binary จำลอง เปรียบเทียบ byte
  ต้นทาง/ปลายทางตรงกัน 100% รวมถึงทดสอบการดาวน์โหลด (ทั้งแบบ inline สำหรับรูปภาพ
  และแบบ attachment สำหรับไฟล์อื่น) และป้องกัน path traversal บน endpoint ดาวน์โหลด

## ข้อจำกัด

- ต้องอยู่ Wi-Fi เครือข่ายเดียวกันระหว่าง PC กับมือถือ (เหมือน AirDrop ต้องใช้
  Wi-Fi ร่วมกันเช่นกัน ในกรณีที่ไม่ได้ใช้ AWDL)
- ไม่มีการเข้ารหัสระหว่างทาง (plain HTTP) — เหมาะสำหรับใช้ในเครือข่ายบ้าน/ที่ทำงาน
  ที่ไว้ใจได้ ไม่ควรใช้บนเครือข่ายสาธารณะที่ไม่น่าเชื่อถือ
- ไม่มีการยืนยันตัวตนผู้ส่ง (ใครก็ได้ที่อยู่ในเครือข่ายเดียวกันและรู้ URL/สแกน QR
  ได้ ก็ส่งไฟล์เข้ามาได้)

## โครงสร้างไฟล์

- `server.py` — เว็บเซิร์ฟเวอร์ทั้งหมด (หน้าเว็บ + endpoint รับไฟล์ + QR code)
- `install.ps1` / `uninstall.ps1` — ตัวติดตั้ง/ถอนการติดตั้งสำหรับ Windows
- `install.sh` — ตัวติดตั้งสำหรับ macOS/Linux
